# 策略目录

这里记录开源版已经写进代码的筛选策略，以及每条策略的来源和时效。后续新增、收紧或退役策略时，在本目录追加一篇，并更新下面的索引。

这些规则只描述本程序如何减少高风险线索进入候选。它们不是买入信号，也不证明某条规则在当前市场上仍然有效。仓库自己的影子表现说明写在根目录 `README.md` 的「筛选效果如何验证」：样本门槛不是盈利证明，统计不含滑点和手续费。

## 怎么追加一条策略

新文件放在 `docs/strategies/`，文件名用 `sNN-短名.md`。文首沿用同一组小节，方便以后对照：

1. **规则**：触发条件和代码里的原话。
2. **来源**：哪次提交、哪个函数、哪份测试把它定下来。没有仓库外的回测或论文时，直接写明。
3. **运行范围**：默认快速扫描会不会执行；缺数据时是排除、等待，还是保持未知。
4. **时效**：它针对的盘面形态，以及 2026 年主流 MEME 发行方式下还剩多少区分度。
5. **状态**：`在用`、`候选` 或 `退役`。候选策略只记录假设，不表示已经改代码。
